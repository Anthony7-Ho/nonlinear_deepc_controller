# Kernel-Based Friction Predictor for Robotic Friction Compensation

This repository implements a model-free friction compensator based on kernel prediction using input-output data only (no explicit friction model).

The method is developed at the [Pd|z Group](https://pdz.ethz.ch/) for high-performance robotic control where precision is critical.

## Prerequisites

- ROS 2 Humble
- libfranka 0.13.0 or newer
- franka_ros2 0.13.1

Install required dependencies before building:

```bash
sudo apt update
sudo apt install nlohmann-json3-dev
pip install mamba-ssm causal-conv1d
```

Reference setup guide: [Franka ROS2 0.13.1 docs](https://polybox.ethz.ch/index.php/s/iYj8ALPijKTAC2z?dir=undefined&path=%2Fgetting%20started%20and%20other%20important%20info%2FInstallation%20Guides&openfile=4252387549)

## Installation

Clone this package into your workspace:

```bash
cd ~/franka_ros2_ws/src
git clone https://github.com/Anthony7-Ho/nonlinear_deepc_controller.git
```

Add the controllers below to `franka_ros2_ws/src/franka_bringup/config/controllers.yaml`:

```yaml
joint_impedance_controller:
  type: nonlinear_deepc_controller/JointImpedanceController

kernel_cartesian_impedance_controller:
  type: nonlinear_deepc_controller/KernelCartesianImpedanceController
```

Build from the workspace root:

```bash
cd ~/franka_ros2_ws
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

Optional: add this to your `~/.bashrc`:

```bash
source ~/franka_ros2_ws/install/setup.bash
```

## Generating Training Data

Training data is generated by exciting the system and logging the response to CSV.

Trajectories should:
- Excite static, Coulomb, and viscous friction effects.
- Cover a wide range of velocities and accelerations.
- Avoid weak excitation that hurts kernel generalization.

### Trajectory Generation Workflow

Use two terminals.

Step 1. Move robot to a start position:

```bash
ros2 launch franka_bringup move_to_start_example_controller.launch.py use_fake_hardware:=false robot_ip:=192.168.1.200
```

Step 2. Start MoveIt and required controllers (leave this terminal running):

```bash
ros2 launch nonlinear_deepc_controller start_moveit.launch.py use_fake_hardware:=false robot_ip:=192.168.1.200
```

Step 3. In a new terminal (after sourcing workspace), run one generator:

- Option A: Joint-space random trajectory (recommended for friction training)

```bash
ros2 launch nonlinear_deepc_controller generate_random_joint_trajectory.launch.py use_fake_hardware:=false robot_ip:=192.168.1.200
```

- Option B: Cartesian random trajectory

```bash
ros2 launch nonlinear_deepc_controller generate_random_cartesian_trajectory.launch.py use_fake_hardware:=false robot_ip:=192.168.1.200
```

- Option C: Mixed sine Cartesian trajectory (test/evaluation utility)

```bash
ros2 run nonlinear_deepc_controller mixed_cartesian_trajectory_generator
```

Important:
- Options A and B must be started with `ros2 launch` (not `ros2 run`) so MoveIt parameters (`robot_description` and `robot_description_semantic`) are available.
- Option C does not use MoveIt and can be run directly.

### Safety Workspace Bounds

The random trajectory generators are constrained to this Cartesian safety box in base frame:

```text
X: [0.30, 0.70]
Y: [-0.40, 0.40]
Z: [0.40, 0.70]
```

If needed, tune sampling and timing in:
- `src/create_random_joint_trajectory.cpp`
- `src/create_random_trajectory.cpp`

## Collecting Input-Output Data

Run the joint impedance controller to execute generated trajectories and log input/output torque data (`tau_ext` as friction proxy):

```bash
ros2 launch nonlinear_deepc_controller joint_impedance_controller.launch.py robot_ip:=192.168.1.200
```

Controller configuration is in `config/joint_impedance_controller.yaml`.

For compatibility with existing scripts, use log names like:

```text
/home/<USER>/franka_ros2_ws/src/nonlinear_deepc_controller/data_processing/tau_log_train.csv
/home/<USER>/franka_ros2_ws/src/nonlinear_deepc_controller/data_processing/tau_log_validation.csv
```

## Testing Friction Prediction

### Generate Cartesian Test/Reference Trajectories

```bash
ros2 run nonlinear_deepc_controller mixed_cartesian_trajectory_generator
```

Use naming convention:

```text
cartesian_test_xyz(1,2,3).csv
cartesian_ref_xyz(1,2,3).csv
```

### Run Cartesian Impedance Controller

Optional start pose:

```bash
ros2 launch franka_bringup move_to_start_example_controller.launch.py use_fake_hardware:=false robot_ip:=192.168.1.200
```

Run controller:

```bash
ros2 launch nonlinear_deepc_controller kernel_cartesian_impedance_controller.launch.py robot_ip:=192.168.1.200
```

Configuration file:

- `config/kernel_cartesian_impedance_controller.yaml`

Kernel-compensated log naming convention:

```text
/home/<USER>/franka_ros2_ws/src/nonlinear_deepc_controller/performance_evaluation/logs/<STIFFNESS>/cartesian_log_kernel_xyz(1,2,3).csv
```

Baseline (no friction compensation): set `alpha_close=0.0` and `alpha_far=0.0`, then use:

```text
/home/<USER>/franka_ros2_ws/src/nonlinear_deepc_controller/performance_evaluation/logs/<STIFFNESS>/cartesian_log_xyz(1,2,3).csv
```

Typical stiffness values used for evaluation: 200, 600, 1000, 2000, 3000.
